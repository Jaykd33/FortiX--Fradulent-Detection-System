# FortiX Backend - Fraud Detection Engine

A production-grade fraud detection platform backend built with FastAPI, SQLAlchemy 2.0, and PostgreSQL.

## Tech Stack

- **Language**: Python 3.10+
- **Framework**: FastAPI
- **Database**: PostgreSQL
- **ORM**: SQLAlchemy 2.0 (with async support using asyncpg)
- **Dependency Management**: Poetry

## Setup Instructions

### 1. Install Poetry

```bash
curl -sSL https://install.python-poetry.org | python3 -
```

### 2. Install Dependencies

```bash
cd fortix_backend
poetry install
```

### 3. Environment Configuration

Copy the environment template and configure your database:

```bash
cp .env.example .env
```

Edit `.env` with your PostgreSQL connection details:

```env
DATABASE_URL="postgresql+asyncpg://username:password@localhost:5432/fortix_db"
```

### 4. Database Setup

Create a PostgreSQL database:

```sql
CREATE DATABASE fortix_db;
```

### 5. Run the Application

```bash
poetry run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

The API will be available at `http://localhost:8000`

### Machine Learning Model Training

The backend includes a comprehensive ML training pipeline for fraud detection:

#### 1. Create Test Data (for development)

```bash
poetry run python scripts/test_training.py
```

#### 2. Train and Evaluate Model

```bash
poetry run python scripts/train_evaluate_model.py
```

This script performs:
- **Data Loading**: Connects to PostgreSQL and loads credit card transactions
- **Exploratory Data Analysis (EDA)**: Analyzes data distribution, class imbalance, and missing values
- **Feature Engineering**: Creates numerical and categorical features with proper scaling
- **Model Training**: Trains a Random Forest classifier with class balancing
- **Model Evaluation**: Comprehensive evaluation with confusion matrix, classification report, ROC-AUC
- **Model Saving**: Saves trained model and preprocessing objects to `ml_models/`

#### 3. Generated Files

After training, the following files are created in `ml_models/`:
- `fraud_model.joblib` - Trained model and preprocessing objects
- `feature_importance.csv` - Feature importance rankings
- `model_evaluation_summary.txt` - Detailed evaluation metrics
- `eda_analysis.png` - Exploratory data analysis visualizations
- `roc_curve.png` - ROC curve plot
